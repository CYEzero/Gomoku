# 五子棋 (Gomoku)

一个基于命令行的五子棋双人对战游戏，使用 Python 3.13 开发。

面向对象和数据结构与算法的实践练习。

## 项目结构

```python
gomoku/
├── main.py           # 入口文件，游戏主循环与输入解析
├── core/
│   ├── types.py      # 基础类型：Stone（棋子）、Color（颜色）、Point（坐标）
│   ├── board.py      # 棋盘类：网格维护、落子、拷贝
│   ├── rules.py      # 规则模块：落子合法性、五子连珠检测
│   └── state.py      # 游戏状态管理：回合、历史、悔棋逻辑
├── pyproject.toml
└── README.md
```

## 快速开始

```bash
uv run python main.py
```

## 游戏规则

- 双方轮流在棋盘上落子，**黑方先手**
- 先在横、竖、斜任一方向连成 **连续五子** 的一方获胜（禁手暂未加入，长连可）
- 棋盘默认大小为 9×9

## 操作指令

| 输入       | 说明                                                    |
| ---------- | ------------------------------------------------------- |
| `行,列`    | 在指定坐标落子，例如 `3,4` 或 `(3,4)`，支持中文逗号     |
| `pass`     | 跳过当前回合                                            |
| `resign`   | 认输                                                    |
| `regret`   | 悔棋（可连续悔棋）                                      |

双方连续两次 `pass` 则游戏以平局结束。
